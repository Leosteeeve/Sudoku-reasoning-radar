Experience

Less reading. More seeing.

Instead of explaining Sudoku in paragraphs, the app shows the pressure on each cell: scan focus, unit highlights, candidate removals, placements, assumptions, and recovery from failed branches.

01 Reasoning playback

02 Command Deck

03 OCR review board

04 Analytics drawer

Workflow

From puzzle input to explainable solution.

Input Click cells, paste strings, load examples, or import images.
Detect Validate givens, detect conflicts, and build candidate masks.
Reason Apply singles, pairs, locked candidates, X-Wing, and MRV search.
Replay Animate placements, removals, guesses, contradictions, and backtracks.
Analyze Report uniqueness, difficulty, technique stats, and branch depth.

Engine

Fast solver core. Separate visual layer.

The solver does not drive the animation directly. It records structured steps; the interface decides how to present them.

03 Human techniques Pairs, locked candidates, X-Wing
04 MRV search Fewest candidates first
05 Result classification Unique / Multiple / Invalid / None
