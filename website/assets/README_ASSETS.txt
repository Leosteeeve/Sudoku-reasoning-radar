Website asset folder for Sudoku Reasoning Radar.

Optional files:
- screenshot.png
  If this file exists, website/script.js will show it in the Visual Preview section.
  If it does not exist, the page uses the built-in CSS mockup instead.

Guidelines:
- Do not store secrets, tokens, cookies, passwords, or private personal files here.
- Keep images reasonably compressed for GitHub Pages.
- Prefer PNG or WebP screenshots of the desktop application.
